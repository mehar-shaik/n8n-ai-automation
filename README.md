# n8n AI Automation Workflow

## About

This repository contains my n8n workflow automation practice. I am learning how to connect applications, APIs, and AI models to automate tasks.

## Workflow

- **Platform:** n8n
- **Workflow type:** AI Agent / Automation
- **AI model:** OpenAI (if configured)
- **Export format:** JSON

## What I Learned

- Creating workflows using nodes and connections
- Configuring triggers and actions
- Working with APIs and JSON data
- Connecting AI models to workflows
- Testing workflow executions and debugging errors

## How to Import

1. Download the workflow JSON file from this repository.
2. Open your n8n editor.
3. Open the workflow menu.
4. Select **Import from File**.
5. Choose the downloaded JSON file.
6. Configure your own credentials and test the workflow.

## Security

This repository must not contain API keys, passwords, access tokens, or other secrets. Configure your own credentials in n8n before running the workflow.
